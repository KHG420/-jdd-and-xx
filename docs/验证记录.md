- Swift 优化构建完成；应用资源完整打包。
- 自动检查 735 条断言通过，包含按时间推进的安静模式检查；这不代表 735 个独立测试案例。
- 睡眠唤醒、连续点击抗议及恢复、放下道具后招呼、提起保持、落地恢复、暂停时保留剩余时长。

- 原生双窗口显示、单人模式、缩放、暂停、隐藏/恢复、手动动作、位置保存及恢复。

- 菜单打开时停止自动切换；屏幕休眠时停止计时器；暂停时降频且不重绘。

- codesign 严格验证、Info.plist 语法验证、启动/构建脚本语法检查通过。
- 打包 ZIP 完整性检查通过。

## 资源占用抽样

早期整图逐帧重绘版本的一次采样约 27.4% CPU。改为缓存 CGImage，由 Core Animation 更新贴图位置、透明度与变换后，同机运行采样约 2.0% CPU、RSS 43,248 KB（约 42 MB）。这是短时进程抽样，不是跨机或长期基准保证。

## 验证边界

实际 GUI 在当前 Mac 验证；负坐标外接屏边界由自动化几何测试覆盖，未宣称在多台实体显示器或所有 macOS 版本上实测。动画是有限姿态的二维精灵动画。应用为本地签名，未做 Apple 公证。

补充：后台 GUI 工具投递拖动后未能确认窗口位移，因此不把该次工具返回的“已投递”当作拖动成功；拖动位移与落地由直接投递给 PetView 的原生 NSEvent 回归测试覆盖。真实窗口已验证的动作限于点击回应、右键菜单及菜单选择。最终应用保持运行，供直接使用。
