桌边的你们 · Windows 版

适用：Windows 10 / Windows 11，64 位 x64。

解压 ZIP 后双击 DesktopPets.exe 即可。它已经包含全部人物素材，
也可以单独复制这个 exe 到其他文件夹。不需要安装 Node、Python、
.NET 或 Visual C++ Redistributable，不需要管理员权限。

右下角系统托盘会出现双人图标，可能被收到“显示隐藏的图标”中。
点击这个图标，可以选择单人/双人、大小、安静陪伴、暂停、隐藏和退出。

点击人物：打招呼；连续点击会闹一点小脾气。
按住拖动：给人物换个位置；松开时缓冲落地并保存位置。
右键人物：选择读书、敲电脑、喝茶、吃饭、小睡、比心或双人动作。
把两个人放近一些：偶尔会靠近，一起看书、比心、拍拍头或拥抱。

程序在本地离线运行，不读取屏幕内容、键盘输入或工作数据。
本地偏好保存在 %APPDATA%\DeskCompanions\settings.ini。

程序未做商业代码签名。如果 Windows 显示未知发布者，请按你自己的
设备策略判断是否运行。开发构建和验证范围见项目 README.md 与 docs。
