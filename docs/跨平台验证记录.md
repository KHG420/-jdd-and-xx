## 发布目标

- Windows 10 / 11 x64：原生 Win32 + GDI+，单个 EXE 内嵌三张人物图集，静态链接编译器运行库。
- macOS 13+：原生 AppKit + Core Animation，通用应用包含 arm64 与 x86_64。

两端使用同一套人物素材，保留点击、拖动、日常动作、四组双人场景、大小调整、单人模式、安静陪伴与本地位置保存。

## 验证边界

没有使用真实 Windows 10 / 11 设备或 Windows 虚拟机；Wine 下通过不能替代实际 Windows 桌面、多显示器、休眠和系统托盘体验验收。未使用实体 Intel Mac，x86_64 运行验证通过 Rosetta 完成。

提供了 Visual Studio 2022 原生构建与测试 PowerShell 脚本，但本次未在 Visual Studio 环境执行。Windows 成品由 MinGW-w64 交叉编译产生。

macOS 使用本地 ad-hoc 签名，未做 Apple 公证；Windows 未配置商业代码签名。测试使用的 Wine 和编译工具不包含在发布包中。
